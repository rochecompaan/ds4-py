# Bake-off Workspace Isolation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prevent grading material from entering agent-visible exercise workspaces and emit task documentation under non-hidden directory names.

**Architecture:** Replace copy-everything-except-test-source staging with an allowlist driven by upstream `.meta/config.json`. Keep tests and grading in `grader_dir`, emit only `TASK.md`, `docs/`, and declared student solution/support files, and retain the existing external-grader execution model.

**Tech Stack:** Python 3.14, stdlib `json`/`pathlib`/`shutil`, pytest, uv.

**Spec:** `docs/specs/2026-11-02-bakeoff-workspace-isolation-design.md`

## Global Constraints

- Upstream `.docs/` and `.meta/` remain valid source-input names; do not modify the pinned benchmark checkout.
- Emit `.docs/` as agent-visible `docs/`.
- Do not emit a `meta/` directory for current exercises; all existing exercise metadata is grading-related.
- Never expose test sources, example solutions, grading metadata, bytecode, or caches before attempt 1 or after grading.
- Keep repository-task preparation unchanged.
- Preserve `TASK.md`, second-attempt grader feedback, and the existing logical—not OS-level—isolation model.
- Give C and ds4-py equivalent sanitized workspaces.
- Do not add prompt wording as a substitute for isolation.

## Review Focus

- Missing or malformed `files.solution` must produce a path-aware `PreparationError`, not a Python mapping/JSON exception.
- Absolute, parent-traversing, or symlink-escaping declarations must not copy anything outside the source exercise.
- A declaration that names a test, `.meta` file, bytecode file, or cache must be rejected rather than treated as a student input.
- Legitimate documentation and declared support files must survive the allowlist, with documentation moved to `docs/`.
- Cloning and repeated grading must preserve the initial isolation boundary for both agent arms, including suppression of ordinary solution bytecode generated by imports during grading.
